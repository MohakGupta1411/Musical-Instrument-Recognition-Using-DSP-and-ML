# Datasets

This project uses the IRMAS dataset and processed audio features for musical instrument recognition.

## 1. Original IRMAS Dataset

The original IRMAS dataset contains audio recordings and annotations for musical instrument recognition.

**Download:** [IRMAS Dataset — Zenodo](https://doi.org/10.5281/zenodo.1290750)

Please download the dataset directly from Zenodo and follow its license and conditions of use.

## 2. Processed Data

The processed data generated and used in this project is hosted on Google Drive due to its large size (approximately 1.89 GB).

[Download Processed Data — Google Drive](https://drive.google.com/drive/folders/1z1UwlLeyzAxu-H1vTmY84sMetHl_5kgb?usp=sharing)

### Data Format

The processed features and labels are stored in NumPy `.npy` format.

The data includes training, validation, and testing arrays used for CNN model training and evaluation.

## 3. Usage

1. Download the processed data from Google Drive.
2. Extract the files.
3. Place them in the appropriate directory.
4. Update the data paths in the Jupyter notebook if necessary.
